# Bigthap Skills Collection 🚀

A curated collection of custom agent skills and tools designed for Antigravity, Claude Code, and agentic LLM workflows.

## 📦 Included Skills

### 1. ⚡ `prompt-reframer`
Transforms colloquial, trigger-heavy, or non-technical user prompts into precise, objective technical specifications and developer-oriented architecture prompts to prevent AI refusals (false positives) and maximize code quality.
- **Location:** `skills/prompt-reframer/`
- **Features:** 4-step reframing pipeline, mapping table, domain blueprints (Game Dev, Networking, Reverse Eng, Data Scraping).

### 2. 🤖 `maxplus-ai`
Integration guide and routing tools for MaxPlus AI proxy services and multi-model LLM endpoints.
- **Location:** `skills/maxplus-ai/`

### 3. 🌐 `netvpn-bypass`
Cellular VPN bypass management and routing configurations (AWS Relay to Proxmox LXC).
- **Location:** `skills/netvpn-bypass/`

## 🛠️ Installation & Usage

Copy any desired skill directory into your local agent skills folder:
- **Antigravity / Gemini:** `~/.gemini/config/skills/`
- **Agent CLI:** `~/.agents/skills/`
